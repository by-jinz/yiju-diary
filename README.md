# 一句

> 把一天，留成一句。

**一句**是一款温暖、简洁的 macOS 日记软件。你可以用一句话或一小段文字记下今天，也可以在一天里继续追加片段；需要时，再让 AI 把中文整理成自然的英文日记表达。

当前为 **v0.3.0 Beta 公开测试版**。这个仓库现阶段主要用于发布安装包和收集使用反馈，暂未开放源代码。

## 下载

请前往 [Releases](../../releases) 页面，在最新版本的 **Assets** 中下载：

`一句-v0.3.0.dmg`

请不要下载 GitHub 自动生成的 `Source code (zip)` 或 `Source code (tar.gz)`，它们不是 Mac 安装包。

## 主要功能

- 月历形式浏览日记，并标记已经记录的日期
- 每天一篇主记录，也可以随时追加多个片段
- 支持“时间线”和“合并全文”两种阅读方式
- 自动保存，并支持编辑和删除
- 点击按钮后，由 DeepSeek 生成自然的英文表达
- 中文修改后，提醒原有英文可能需要重新生成
- 导出 JSON 备份，并安全地导入、合并旧记录
- 日记默认只保存在当前 Mac
- DeepSeek API 密钥保存在 macOS 系统钥匙串中

## 系统要求

- macOS 14 或更高版本
- 支持 Apple 芯片和 Intel 芯片的 Mac
- 使用 AI 英语功能时需要网络连接
- AI 英语功能需要用户自己的 DeepSeek API 密钥

## 安装方法

1. 下载并打开 `一句-v0.3.0.dmg`。
2. 把“一句”拖入旁边的 **Applications** 文件夹。
3. 打开“应用程序”文件夹，按住 `Control` 点击“一句”，选择“打开”。
4. 如果仍然被 macOS 拦截，请前往“系统设置 → 隐私与安全性”，找到“一句”并选择“仍要打开”。

> 当前测试版尚未使用 Apple Developer ID 证书签名，也没有经过 Apple 公证，因此第一次打开时会出现安全提醒。只应从本仓库的 Releases 页面下载。

## 使用 AI 英语功能

1. 打开“一句”左下角的设置。
2. 前往 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建自己的 API 密钥。
3. 将密钥粘贴到设置页，点击“保存并测试”。
4. 写完中文日记后，点击“生成英文”。

“一句”本身不收取 AI 翻译费用。DeepSeek API 是否收费及具体费用以 DeepSeek 官方规则为准，请不要与他人共享自己的 API 密钥。

## 隐私

- 日记正文和生成的英文默认保存在当前 Mac。
- API 密钥只保存在 macOS 系统钥匙串中，不会写入日记或备份。
- 只有用户主动点击“生成英文”时，当天的中文内容才会发送给 DeepSeek API。
- 保存并测试密钥时会查询 DeepSeek API 账户状态，但不会发送日记内容。
- 当前版本没有登录系统、广告或使用行为统计。

完整内容请阅读 [隐私说明](PRIVACY.md)。

## 反馈

请前往 [提交反馈](../../issues/new/choose) 选择合适的模板。提交前请移除日记正文、DeepSeek API 密钥、备份文件和其他私人信息。

## 当前已知限制

- 尚未经过 Apple 公证，首次启动需要手动允许
- 暂不支持 iCloud 同步或多设备同步
- 暂无自动更新，需要从 Releases 手动下载新版本
- 当前界面以简体中文为主
